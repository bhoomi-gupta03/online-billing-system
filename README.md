SmartCart – Online Shopping System
Overview

SmartCart is a console-based e-commerce application developed using C++, OOP concepts, STL, and SQLite. The project simulates a real-world online shopping platform where users can browse products, manage carts, calculate bills, and authenticate securely.

This project is designed to strengthen problem-solving, backend logic, database integration, and software development skills for placement preparation.
